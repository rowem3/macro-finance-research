# macro-finance-research

A collection of R and Python projects from my coursework in economics and finance at Georgetown University. Topics include panel data econometrics, probit modeling, machine learning, and financial markets analysis.

## R Projects
| Folder | Description |
|--------|-------------|
| `ECN481_Banking_Deserts` | Senior thesis — probit model analyzing determinants of banking deserts across U.S. census tracts |
| `BAC_Economic_Growth` | Panel regression (FE/RE + Hausman test) on OECD macroeconomic and institutional freedom data |
| `BSA420_Used_Car_Pricing` | KNN and linear regression models to predict used car prices |
| `ECN314_Econometrics` | Econometric studies on economic freedom, purchasing power parity, and interest rate parity |
| `FIN306_Credit_Quality` | Regression analysis of bank customer credit quality and loan approval outcomes |
| `FIN304_Currency_Analysis` | Exchange rate analysis across 8 major currency pairs using Yahoo Finance data |

## Python Projects
| Folder | Description |
|--------|-------------|
| `FIN403_Currency_Analysis` | Pulls live forex data via yfinance and computes daily percent changes across currency pairs |
| `FIN306_Credit_Quality` | Logistic regression on bank customer data using statsmodels |
| `BAC_Models` | Jupyter notebook with additional macroeconomic modeling work |
