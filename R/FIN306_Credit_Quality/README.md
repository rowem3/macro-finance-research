# FIN 306 — Bank Credit Quality Analysis

OLS regression model examining determinants of bank customer creditworthiness and loan approval.

**Variables:** income, savings, loan amount requested, employment status, education level, marital status, credit score, previous defaults

**Output:** regression table via `stargazer`, correlation matrix via `corrplot`

**Packages:** `stargazer`, `readxl`, `broom`, `corrplot`
