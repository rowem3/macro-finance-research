# ECN 314 — Applied Econometrics Studies

A set of regression studies from my applied econometrics coursework covering international economics and macro topics.

**Scripts:**
- `Freedom_Index_GDP_regression.R` — OLS regression of GDP per capita (PPP) on Heritage Foundation freedom scores across countries
- `Crypto_PPP_test.R` — Tests purchasing power parity using cryptocurrency price data
- `Crypto_IRP_test.R` — Tests interest rate parity with crypto exchange rate data
- `20250404_correlation_test.R` — Correlation analysis for semester project

**Packages:** `stargazer`, `broom`, `ggplot2`
