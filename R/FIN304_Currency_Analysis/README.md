# FIN 304 — Currency Exchange Rate Analysis

Pulls daily and weekly exchange rate data for 8 major currency pairs (BRL, NZD, CHF, CNY, GBP, EUR, MXN, RUB) against USD via Yahoo Finance and visualizes trends over a 3-month window.

**Outputs:** daily and weekly line charts, pivot tables of exchange rates by currency

**Packages:** `quantmod`, `ggplot2`, `dplyr`
